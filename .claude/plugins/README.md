役割:
  プラグイン (skills / agents / hooks / commands などをまとめた拡張パック) の

  ディレクトリ構造を持つ:

    .claude/plugins/<plugin-name>/
      ├── plugin.json     # メタ情報 (name, version, description, entry など)

      ├── agents/         # プラグイン提供のサブエージェント
      ├── hooks/          # プラグイン提供のフック
      └── commands/       # プラグイン提供のスラッシュコマンド

使い方:
  1. 新しいプラグインを作るときはこのディレクトリ配下にサブディレクトリを切る。
  2. settings.json の "plugins" でロードしたいプラグインを指定する (※将来仕様)。
  3. 外部公開する場合は、独立リポジトリにしてマーケットプレイス経由で配布する。

注意:
  - 外部由来のプラグインを置く場合は、出所と権限 (フック / Bash 実行) を必ず
  　確認する。任意コード実行が含まれるため、信頼できないものは入れない。
  - このディレクトリ自体は空でも問題ない。本ファイルは置き場の説明用。
