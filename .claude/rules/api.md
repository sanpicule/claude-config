# API ルール

> このファイルは `src/api/**` や `app/api/**` 配下を編集するときに優先して適用する。

## 共通

- すべてのエンドポイントは `/api/v<番号>/` 配下に配置する。破壊的変更は新バージョンを切る。
- リクエスト / レスポンスは JSON。文字コードは UTF-8 固定。
- 認証は `Authorization: Bearer <token>` を必須とする (公開エンドポイントを除く)。

## エラーハンドリング

- 4xx / 5xx 応答は以下の形式に統一する:
  ```json
  { "error": { "code": "string", "message": "human readable", "details": {} } }
  ```
- スタックトレースやクエリ文字列など、内部実装が漏れる情報を `message` に含めない。

## 入出力バリデーション

- すべての入力は型スキーマ (zod / pydantic / TypeBox など) で検証してから処理する。
- 数値・日付は文字列として受け取り、サーバ側で正規化する。
- 出力はレスポンス専用スキーマでフィルタする (内部フィールドの漏洩防止)。

## パフォーマンス

- DB アクセスは N+1 を許容しない。`include` / `join` / DataLoader で解決する。
- 一覧系は必ずページネーション (`limit` / `cursor`) を実装する。
