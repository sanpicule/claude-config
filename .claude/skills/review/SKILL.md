# Review Skill

## 手順
1. `scripts/collect-diff.sh` を実行して、レビュー対象の差分を取得する。
2. 差分に対して以下の観点で評価する:
   - 可読性 / 命名 / 単一責任
   - バグや境界値、エラー処理
   - セキュリティ (秘匿情報、入力検証)
   - パフォーマンス (N+1、無駄なループ)
   - テスト不足
3. `example.txt` のフォーマットに従って結果を出す。

## 出力形式
`example.txt` を参照すること。フォーマットを勝手に変えない。

## 注意
- 編集はしない。指摘と修正案の提示に留める。
- 差分の外まで読みに行くのは関連が明らかな場合のみ。
